# Personal Portfolio Website

A modern, responsive, and animated personal portfolio website built using **React**, **Vite**, and **Tailwind CSS**.  
This portfolio showcases my skills, projects, experience, and achievements in a clean, professional, and recruiter-friendly format.

---

## 🔹 Features

- Responsive design for desktop and mobile devices
- Modern UI with consistent spacing and typography
- Smooth scroll-based animations using Framer Motion
- Fixed, transparent navigation bar with smooth scrolling
- Clean section-based layout (Home, About, Skills, Projects, etc.)
- Single professional profile image for visual consistency
- Organized and scalable component structure
- Optimized for deployment on platforms like GitHub Pages, Netlify, or Vercel

---

## 🔹 Tech Stack

**Frontend**
- React (Vite)
- Tailwind CSS
- Framer Motion
- Typed.js

**Tooling**
- Vite
- ESLint
- PostCSS
